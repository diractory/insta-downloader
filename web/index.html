// WHAT IT DOES

Built for both DMs and busy groups

Every feature below works the moment the bot is invited — no extra config beyond making it an admin where needed.

📥

Instant Reel Downloads

Paste a link, watch a live progress bar for both the download and the Telegram upload, get the file with one tap.

📝

Caption on Demand

Every download ships with a "Show Caption" button so the original post text is never lost, but never clutters the chat either.

🛡️

Full Group Moderation

Mute, ban, unban, kick, promote, warn, purge, and pin — the same toolkit you'd expect from a dedicated group-management bot.

🔒

Force-Subscribe Gate

New users are asked to join the official channel before their first DM download — one tap, then they're in.

📢

Owner Broadcast Tools

Reach every user or every group the bot is in with a single reply-and-send command.

⚙️

Self-Installing

Missing a Python package? The bot installs it the moment it boots — no manual pip install required.

// REFERENCE

Command reference

Group-admin commands work by replying to a member's message, or passing their @username / numeric ID.

CommandAccessDescription
/starteveryoneStarts the bot, shows your Telegram info + profile picture
(paste a link)everyoneDownloads the Instagram reel/post with a live progress bar
/mute · /unmutegroup adminRestrict or restore a member's messaging rights
/ban · /unban · /kickgroup adminRemove members from the group
/promote · /demotegroup adminGrant or revoke admin rights
/warn · /resetwarngroup adminTrack warnings — 3 strikes auto-bans
/purge · /pin · /unpingroup adminBulk cleanup and pinned-message control
/broadcast · /gbroadcastownerMessage every user / every group
/stats · /id · /info · /pingeveryone / ownerUtility & diagnostics commands
// DEPLOYMENT

Live in four steps

1

Get API credentials

Create an app at my.telegram.org for API_ID / API_HASH, and a token from @BotFather.

2

Set environment variables

Copy .env.example, fill in your credentials and owner ID.

3

Push to Render

Connect your repo — render.yaml configures the build and start commands automatically.

4

Promote it in your group

Add the bot, make it admin, and every moderation command unlocks instantly.
